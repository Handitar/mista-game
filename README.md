#Опис
Гра для однієї людини проти комп'ютера. Гравець і комп'ютер по черзі називають міста, кожне наступне місто повинно починатися на останню літеру попереднього міста.

#Вимоги
- Java 11 або вище
- будь-яке IDE для Java(бажано IntelliJ IDEA)

#Запуск у IntelliJ IDEA
1. Відкрийте проект у IntelliJ IDEA
2. Відкрийте файл `AppLauncher.java`
3. Натисніть `Shift + F10` або на зелену кнопку "Run"

#Як грати
1. Запустіть програму
2. Натисніть "Старт" у вітальному вікні
3. Введіть назву українського міста у текстове поле
4. Натисніть кнопку "Зробити хід" або Enter
5. Комп'ютер дає відповідь
6. Продовжуйте доти, доки один з гравців не програє
7. Виберіть "Так" щоб зіграти ще або "Ні" щоб вийти

#Правила
- Місто має починатися на останню літеру попереднього міста
- При визначенні останньої літери ігноруються: ь, й, апостроф та дефіс
- Кожне місто можна назвати тільки один раз
- Натисніть "здаюсь" щоб здатися та програти
